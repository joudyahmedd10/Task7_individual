# Turtle Task
 The task asked for the turtle to move using the keyboard and to print the dominant color 

 ## Features 
 - Turtle moves using ( W/A/S/D)
 - it senses the color surrounding
 - it prints out the dominant color

## Requirements
- install Ros2 jazzy
- install Turtlesim
- python
- Ubuntu 24.04

# Challenges faced during task
- taking input from the keyboard
- subscribing to color sensor
